MRC Plugin for ImageJ

To install:
Place the .jar file in the Plugins folder of ImageJ (found with File->Show Folders) and restart ImageJ.
To Read MRC: Drop the file to the body of the ImageJ widget or use MRC_Plugin/Read.
To Write MRC: Use Save As -> MRC Write or use MRC_Plugin/ Write.

To uninstall:
Remove the jar file both from the Plugins folder and its jars subfolder
